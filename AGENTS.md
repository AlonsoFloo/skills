# AGENTS.md

## Purpose

This repository contains reusable engineering skills for AI coding assistants and human engineers.

## Instructions

When using this repository as context:

1. Identify the skills relevant to the task.
1. Read the complete `SKILL.md` for each relevant skill.
1. Apply the rules while preserving the project's existing architecture and conventions.
1. Do not invent exceptions silently. Explain material deviations.
1. Prefer the narrowest applicable skill over unrelated guidance.
1. When changing a skill, keep examples executable or clearly marked as illustrative.

## Skill selection examples

- Architecture decision → `core-engineering`
- Domain modeling / validation / patterns → `core-engineering` + `code-logic`
- Unit tests / Flow tests → `testing`
- Android feature → `android-kotlin` + relevant core/testing skills
- Swift/iOS feature → `ios-swift` + relevant core/testing skills
- CI/CD, dependencies, releases → `devops-tooling`
