## Gradle Dependency Verification Example

Gradle allows pinning artifacts by exact checksum in
`verification-metadata.xml`.

```xml
<verification-metadata>
    <configuration>
        <verify-metadata>true</verify-metadata>
        <verify-signatures>true</verify-signatures>
    </configuration>
    <components>
        <component group="com.squareup.retrofit2" name="retrofit" version="2.9.0">
            <artifact name="retrofit-2.9.0.jar">
                <sha256 value="03bb543883a48e7e178122...exact_hash_here...84fc" origin="Generated by Gradle" />
            </artifact>
        </component>
    </components>
</verification-metadata>
```
