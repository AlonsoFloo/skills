# Devops Tooling

> DevOps, AI-assisted development & supply-chain security

This skill is derived from the **Core Engineering Skills** specification supplied with this repository.
Treat the rules below as engineering guidance for AI coding assistants, code reviewers, and engineers.
When a rule is context-dependent, prefer explicit domain reasoning over mechanical application.

## Rule 21: Enforce Detailed Commit Messages for AI-Assisted Code

**Description:** When utilizing AI coding assistants, git commit messages must be extra thorough and detailed. Document the intent, architectural reasoning, generated files, human review steps, and tests performed to ensure auditability. Prefix the commit message with `AI.`.

**❌ DON'T**

```text
git commit -m "AI fixes"
```

**✅ DO**

```text
feat(auth): AI. refactor biometric authentication flow using Koin DI

- Replace direct BiometricPrompt instantiation with BiometricSecretSigner contract
- Add unit tests using FakeBiometricSecretSigner test double
- Verify automated UI test passes on Android API 34 and iOS simulator
- AI-assisted generation reviewed and verified by engineering team
```

## Rule 22: Pin Dependencies and Enforce Cryptographic Digests

**Description:** Always pin exact library version numbers and lockfile checksums/digests. Never rely on floating range tags like `latest` or `^1.0.0`. Whenever the build system supports it, all third-party libraries must be pinned to a specific cryptographic digest (SHA-256) to guarantee artifact integrity and prevent supply chain attacks.

**❌ DON'T**

```dockerfile
# Trusting floating version, vulnerable to breaking changes
FROM node:latest
```

```gradle
// Trusting only the version number, vulnerable to artifact tampering
dependencies {
    implementation("com.squareup.retrofit2:retrofit:2.9.0")
}
```

**✅ DO**

```dockerfile
# Pinning exact version and hash
FROM node:20.11.1-alpine@sha256:c77dc7458157...
```

```xml
<!-- gradle/verification-metadata.xml -->
<!-- Pinning dependencies using Gradle Dependency Verification -->
<verification-metadata>
    <components>
        <component group="com.squareup.retrofit2" name="retrofit" version="2.9.0">
            <artifact name="retrofit-2.9.0.jar">
                <sha256 value="03bb...exact_hash_here...84fc" origin="Generated by Gradle" />
            </artifact>
        </component>
    </components>
</verification-metadata>
```
