# AGENTS Reference Template (`AGENTS.md`)

```markdown
# AGENTS.md

## Overview

Guidance and instructions for AI coding assistants working in this repository.

## Instructions

1. **Coding Standards**:
   - Follow established code patterns and project structure.
   - Never commit secrets, API keys, or unverified binary dependencies.
   - Enforce explicit typing, immutability, and modular design.

2. **Commit Messages**:
   - Adhere to Conventional Commits format (`feat:`, `fix:`, `refactor:`, `docs:`, `chore:`).
   - Use `AI.` prefix in commit messages generated by AI assistants.

3. **Pre-Commit Verification**:
   - Run `pre-commit run --all-files` before finalizing changes.
```
